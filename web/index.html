Ranked by cosine similarity of the films' genre + keyword tags.

    How it works

    1. Tags — every film has hand-written genre and keyword tags in data/movies.csv.
    2. TF-IDF — turns each film's tags into a vector; rare, specific tags weigh more.
    3. Cosine similarity — measures the angle between two films' vectors.
    4. Recommend — the smallest angles to your pick win. No user history needed.

    Python version: python recommend.py "3 Idiots" --genre Comedy --top 3. The film data here is generated from the same CSV by gen_web_data.py.
