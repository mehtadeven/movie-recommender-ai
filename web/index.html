Movie Recommender

Content-based filtering · TF-IDF + cosine similarity · 60 films

Pick a film you like and get the titles closest to it, computed live in your browser from each film's genre and keyword tags. No ratings, no user history, no server.

ADMIT ONE

Tonight's double features

Ranked by cosine similarity of the films' genre + keyword tags.

    Behind the scenes

    1. TagsEvery film has hand-written genre and keyword tags in data/movies.csv.
    2. TF-IDFTurns each film's tags into a vector, so rare, specific tags weigh more.
    3. Cosine similarityMeasures the angle between two films' vectors.
    4. RecommendThe smallest angles to your pick win. No user history needed.

    Python version: python recommend.py "3 Idiots" --genre Comedy --top 3. This page's film data is generated from the same CSV by gen_web_data.py.
